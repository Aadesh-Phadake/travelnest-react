# FFSD Project  
## TravelNest – Hotel Management System Website

---

## 📌 Project Description
TravelNest is a full-stack Hotel Management System website that allows users to browse hotels, view details, and manage bookings. The application provides a smooth user experience with separate frontend and backend services.

---

## 🛠 Tech Stack
- **Frontend:** React / Vite, HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Tools:** npm, nodemon

---

## ▶ Instructions to Run the Project

### 🔹 Run the Backend
```bash
cd backend
npm install
nodemon app.js
```

### 🔹 Run the Frontend
```bash
cd frontend
npm install
npm run dev
```

### 🔹 Open the browser and visit:

http://localhost:5173
